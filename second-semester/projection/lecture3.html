CASE-средства для проектирования ПО

Определение CASE-средств

CASE (Computer Aided System Engineering) - средства компьютерной поддержки проектирования систем.

Основные преимущества

  • Сокращение сроков разработки
  • Уменьшение трудозатрат
  • Повышение качества разработки
  • Уменьшение количества ошибок

Функциональные возможности

  • Систематизация информации о проекте
  • Визуальное моделирование с использованием диаграмм
  • Анализ стоимостных и временных характеристик
  • Использование типовых решений и компонент
  • Автоматическая кодогенерация

Классификация CASE-средств

1. Средства управления проектом

Функции: формирование календарных графиков, управление ресурсами, управление затратами.

Пример: Microsoft Project

2. Средства создания диаграмм

Функции: формирование информационной системы, формирование информационной модели, анализ эффективности.

Примеры: Design/IDEF, BPWin

Пример применения

Страховая компания ЗАО «Макс»

Инструмент: ALLFUSION PROCESS MODELER V 4.1

Результат: построена функциональная модель бизнес-процессов

Элементы модели:

  • Входные данные: Страхователь, Сопроводительная документация
  • Механизмы: Страховые агенты, Сотрудники, Оборудование
  • Управление: Условия страхования, Законодательство РФ
  • Выходные данные: Статистические данные, Оказанные услуги, Выплаты

Методологии моделирования

  • UML (Unified Modeling Language)
  • BPMN (Business Process Model and Notation)
  • ER-диаграммы (Entity-Relationship)

Специфика инструментов

Design/IDEF

Графическая среда для проектирования сложных систем.

Поддерживает методологии: IDEF0, IDEF1, IDEF1X, E-R, IDEF/CPN.

BPWin

Инструмент для моделирования и анализа бизнес-процессов.

Позволяет оптимизировать деловые и производственные процессы.
